1. Updated Problem Statement (New Changes & Threat Expansion)

In Phase-1, we defined four critical failure modes: supply-chain slopsquatting, credential/PII leakage, unbounded AST blast radius, and prompt injection loops. During Phase-2, as KAVACH evolved into an enterprise multi-agent highway, four critical new threat vectors emerged:

  • Financial Transaction Vulnerabilities (OWASP LLM01:2025): Extending agents into core banking introduces transaction memo prompt injection, balance desynchronization without ACID atomicity, and violations of statutory RBI directives mandating High-Value Escrow quarantine for transfers exceeding ₹50,000.
  • Polyglot Supply-Chain Slopsquatting: Hallucinated dependencies extend beyond Python to npm (`package.json`) and Go (`go.mod`), requiring a multi-ecosystem AST package firewall.
  • Statutory Indian DPDP Act 2023 Compliance: Mandates zero-knowledge tokenization so that raw Aadhaar or PAN identifiers are never written even to internal database logs.
  • Cryptographic Tamper-Evidence: Replaces modifiable SQLite/JSON audit trails with append-only NIST SHA3-512 Merkle DAGs for forensic non-repudiation.
