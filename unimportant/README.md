# 📦 KAVACH: Archived & Legacy Artifacts (`unimportant/`)

This directory contains **archived, intermediate, legacy, and draft files** that are no longer needed in active development but are preserved for audit and historical reference.

---

## 📁 Subdirectory Breakdown

### 1. `01_Archived_Legacy_Phases/`
* `archive/`: Previous development phases, prototype scripts, and deprecated workflows.

### 2. `02_MidSem_Rough_Work/`
* `mid-sem-rough-work/`: Scratchpad files, early draft presentations, intermediate test runners, and exploratory scripts used during the midterm preparation.

### 3. `03_Older_Documentation_Dumps/`
* `Agentic_AI_Documentation/`: Raw documentation drafts prior to final consolidation.
* `PRJ_IV_Documentation/`: Earlier versions of synopsis reports and midterm presentation slides.
* `docs/`: Legacy presentation files (`KAVACH_Presentation.pptx`, `new_additions.pptx`) and reference materials.
* `pptmaker_docs/`: Early PowerPoint generators, legacy 15-slide drafts, and previous markdown breakdowns.
* `research_raw/`: Unprocessed research notes and preliminary experiment outputs.

### 4. `04_Scratch_and_OneOff_Scripts/`
* `scratch/`: One-off utility scripts (e.g., `move_playbook.py`).
* `test_verify_frontend.py`: Standalone DOM element verification script.
* `test_verify_motion_design.py`: One-off CSS motion and keyframe verification script.
* `test_verify_terminal_results.py`: Standalone CLI formatting verification script.
* `security_gate_report.json`: Historical CI security gate run output.
* `organize_workspace.py`: Workspace migration script.

### 5. `05_Old_Demo_Prototypes/`
* `repo_scanner_demo/`: Early standalone repository scanner prototype built before the unified KAVACH platform was operationalized.
