# 🌟 KAVACH: Important & Official Project Artifacts

This directory contains **all the essential, verified, and official assets** of the **KAVACH** Capstone Project (`PRJ-IV` & `CSE3101` Agentic AI).

---

## 📁 Directory Structure & Contents

### 1. `kavach/` (Core Platform & Codebase)
The complete operational, containerized software engineering platform:
* `backend/`: FastAPI REST endpoints, Agentic RAG, AST blast radius, Dual-Engine LLM router, Sentinel guardrails.
* `frontend/`: Dark-mode Mission Control dashboard (`#08090D` slate, `#00D2FF` cyan), real-time SSE telemetry, and multimodal Groq Whisper speech-to-text.
* `tests/`: 164+ automated unit, integration, and security gate tests.
* `data/`: Multilingual test corpus (Hinglish PII, Aadhaar/PAN) and AST impact test cases.
* `demo_repo/`: Interactive test repository for live vulnerability simulations.
* `verify_project.py`: One-command automated verification script.

### 2. `01_Master_Presentations/`
The definitive presentation decks for midterm and final evaluation:
* `KAVACH_PERFECT_COMPREHENSIVE_MASTER_DECK.pptx`: The master 24-slide widescreen presentation deck with full speaker notes.
* `KAVACH_Interactive_Presentation.html`: Standalone interactive web presentation deck with live Mermaid flowcharts and keyboard navigation.
* `KAVACH_PERFECT_MASTER_PRESENTATION_24_SLIDES.md`: Complete slide-by-slide speaker scripts, rubrics mapping, and timing breakdown.
* `build_perfect_master_presentation.py`: Python script to regenerate the master PowerPoint presentation.

### 3. `02_Official_Reports_and_Synopses/`
The formal academic deliverables:
* `PRJ_IV_SYNOPSIS_REPORT.docx` & `PRJ_IV_SYNOPSIS_REPORT.md`: Comprehensive midterm project synopsis report.
* `KAVACH_AGENTIC_AI_MASTER_BLUEPRINT.md`: Exhaustive academic specification and CSE3101 course syllabus alignment matrix.
* `KAVACH_MidTerm_Synopsis_Report.docx`: Formal mid-term project synopsis document.
* `PHASE_1_PROJECT_CHARTER.md`: Project charter and governance contracts.
* `PEAS_AND_PERSONA_SPECIFICATION.md`: PEAS specification for agentic workflows.
* `KAVACH_Limitations_and_Part2_Improvement_Blueprint.pdf`: Research limitations and Phase 2 improvement blueprint.

### 4. `03_Architecture_and_Flowcharts/`
Formal system architecture and workflow diagrams:
* `01_system_architecture.mmd`: 5-Tier system topology diagram.
* `02_five_phase_pipeline.mmd`: End-to-end execution lifecycle sequence.
* `03_ast_package_firewall.mmd`: AST package firewall and PyPI slopsquatting interception flowchart.
* `04_multilingual_pii_vault.mmd`: Zero-Knowledge token vault workflow for Indian DPDP Act 2023 compliance.
* `05_react_self_healing.mmd`: Closed-loop ReAct self-healing reflection engine flowchart.
* `flowchart_viewer.html`: Interactive browser viewer for all architectural diagrams.
* `FLOWCHARTS_AND_EXPLANATION.md`: Technical breakdown of all flowcharts and mathematical formulations.

### 5. `04_Viva_Defense_and_Evaluation/`
Preparation materials for faculty examination and viva defense:
* `VIVA_DEFENSE_AND_EVALUATION_GUIDE.md`: Top examiner trap questions, mathematical proofs, and model answers.
* `VIVA_DEFENSE_CHEATSHEET.md`: Quick-reference defense cheatsheet.
* `42_RUNS_EVALUATION_DATASET.md`: Empirical performance dataset across 42 full-lifecycle workflow runs.
* `CRITICAL_PLAY_AREAS_EVALUATION.md`: Detailed rubric evaluation matrix.
* `TEAM_RESPONSIBILITY_MATRIX.md`: Subsystem ownership and contributions per team member.
* `PROJECT_TIMELINE_CSE3101.md`: Sprint schedules and milestone tracking.
* `PROMPT_STRATEGIES_AND_RAG_STUDY.md`: Theoretical study on ReAct, CoT, and dense embeddings.

### 6. `05_IEEE_Research_Publication/`
Academic publication deliverables:
* `research/ieee_publication/`: Complete research paper draft, IEEE submission bundle, LaTeX tables, figures, and benchmark experiments.
