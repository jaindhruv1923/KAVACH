🔄 ReAct Pattern & Self-Correction Mechanism

Unlike hardcoded sequential pipelines, KAVACH implements the iterative Reason + Act loop:

Goal → Thought → Action(Tool, Args) → Observation → Reflection → Final Answer

Autonomous Self-Correction: When an execution step returns an error (e.g. failing test or syntax error), the engine triggers an explicit `[Self-Reflection]` note, analyzes the traceback, and formulates an adapted repair action.

🤝 Agent-to-Agent (A2A) Protocol & Shared Blackboard

Agents do not operate in silos. They communicate via structured message passing on a thread-safe `SharedBlackboard`:

  • DELEGATE_TASK: Orchestrator assigns sub-goals to specialist agents.
  • REPORT_OBSERVATION: Specialists publish findings back to the blackboard.
  • SECURITY_ALERT: Sentinel halts hostile ingress upon prompt injection detection.
  • TASK_COMPLETE: Verifier certifies empirical satisfaction of invariants.
